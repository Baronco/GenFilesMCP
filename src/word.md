Generate a Word (.docx) document. Supports two authoring modes: a Python script (`python-docx`) or structured YAML (cover, columns, and body elements). The **word** skill also covers reviewing an existing document by adding comments.

Before calling, consult the **word** skill for the authoring (and review) format and rules. Use `fetch_uploaded_chat_file_ids` to get the IDs of any images uploaded in the chat that should be embedded.
